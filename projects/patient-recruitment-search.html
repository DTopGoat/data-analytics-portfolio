Streamlit · Python · Snowflake · SQL

Patient Recruitment Search Application

A clinical research recruitment tool designed to help recruiters quickly identify potential candidates from large patient datasets using configurable medical and operational criteria.

Advanced Patient Filtering

Search by medical conditions, concomitant medications, laboratory procedures, visit completion, and study visit criteria.

Laboratory Value Search

Supports exact values, ranges, and multiple laboratory procedures while returning the latest relevant patient results.

Recruiter-Friendly Output

Selected laboratory values and recruitment criteria are surfaced directly in the patient results to make review faster and easier.

Closest Site Ranking

Ranks nearby research sites for each potential candidate to help recruitment teams identify practical enrollment locations.

Data Standardization

Normalizes medical conditions, medication names, laboratory values, and operational fields to improve search consistency.

Warehouse Integration

Uses Snowflake SQL and reusable query logic to retrieve current patient-level information for the Streamlit application.

Typical workflow

Recruitment criteria → Streamlit filters → Snowflake SQL → latest patient data → eligibility-focused result set → closest-site ranking.
